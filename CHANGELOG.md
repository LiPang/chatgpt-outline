# Changelog

- Prefer explicit heading numbering over inconsistent HTML heading ranks.
- Keep Chinese numbered sections at the same logical level.
- Align numeric subheadings and unnumbered descendants with their parent sections.

- Reveal second- and third-level headings progressively on hover.
- Exclude fourth-level and deeper headings.
- Add keyboard navigation between hierarchy levels.

## 1.0.0
